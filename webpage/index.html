The "Clever Hans" Problem

When you ask a model about "Lehman Brothers", it does not simulate the balance sheet. It retrieves the Wikipedia entry for 2008. This is Look-Ahead Bias.

Standard masking (removing dates) fails because semantic triggers remain. Our solution uses Linear Probe Steering to force the model into a "Reasoning State" ($P(token|logic)$) rather than a "Memory State" ($P(token|history)$).
